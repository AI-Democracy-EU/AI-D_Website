Wie bereits festgestellt, bezieht sich GenAI auf Systeme, die Inhalte wie Text, Bilder, Musik oder Code basierend auf trainierten Modellen und Benutzeranweisungen erstellen. Diese Systeme basieren auf maschinellem Lernen (ML) von Mustern durch enorme Datenmengen, wodurch sie neue Muster generieren können, indem sie basierend auf statistischen Modellen und Wahrscheinlichkeiten „raten“. Dies kann Text, Sprache, Musik, Bilder, Code oder jede andere Form umfassen, die in Muster abgebildet werden kann. Bots wurden mit unzähligen Daten aus verschiedenen Quellen trainiert, insbesondere aus dem Netz und hauptsächlich aus dem globalen Norden und in englischer Sprache.

### Wie funktionieren LLMs?

LLMs operieren jedoch oft ohne spezifische Richtlinien, wie etwas verstanden oder interpretiert werden soll. Um dem entgegenzuwirken, integrieren sie menschliches Feedback und ethische Regeln, um ihre Ausgaben zu verfeinern und sicherzustellen, dass sie den Erwartungen der Benutzer entsprechen. KI-Prompting ist die Eingabe spezifischer Anweisungen, um die Ausgabe der KI zu steuern, wie z. B. das Generieren von Text oder Bildern, wodurch Benutzer die Ergebnisse beeinflussen und anpassen können.
