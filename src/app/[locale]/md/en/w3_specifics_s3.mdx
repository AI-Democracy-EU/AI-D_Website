The first figure shows in a very simplified way the data generation process, which begins with data
collection. The globe on the left side should not give the misleading impression that AI would map
the whole world. No AI system has a world model, only a data model for its specific purpose. E.g.
autonomous driving needs a model of its systemic environment that is more dynamic and that processes
a lot of data from sensors in addition.

The data collection process for building a data model involves in general defining a target population and sampling from it, as well as identifying and measuring features and labels. This dataset is split into training and test sets.

Historical bias occurs when historical data reflects societal biases and prejudices.

Representation bias occurs when the data used to train AI models is not representative of the target population.

Measurement bias occurs when data collection methods contain systematic errors.
