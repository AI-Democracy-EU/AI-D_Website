### Natural Language Processing (NLP)

NPL helps generate language that makes dialogues human-like. NLP is the newer term for computer linguistics, and it has become an essential technology for generative AI with integrated chatbots (e.g. ChatGPT, etc.). This means that the interaction is based on natural language. So, you can simply enter anything in your natural speech to interact with the AI system. AI tutors combine this technology with Machine Learning.

### Adaptive Learning Technologies (ALT)

The key to ALT is the dynamic adjustment of content delivery, assessment and feedback. The AI system can react to the student's learning capacity in real-time.
Adaptive learning is a way of using data to make learning experiences more tailored to each student's needs. These systems can, for instance, track student progress, engagement and performance and adapt learning materials in real time to provide personalised learning experiences, based on the user data.

**ALT** uses Machine Learning, Deep Learning algorithms and data analytics to customise the learning experience.
