- ChatGPT, for example, is often used as a tutor but is not explicitly designed for learning purposes.
- Applications like Duolingo MAX integrate GPT-4, the technology used for ChatGPT.
- Language translation tools like DeepL.com are good for learning and practising different languages and training and testing vocabulary. Tools like that can increase accessibility by reducing language barriers.
- Other tools create images from PDFs and produce alt texts for screen readers in HTML. Applications like this can help students with visual impairment.
