# AI-D_Website
Source files for the website created for project AI.D

This repository contains the source files for the website of project AI.D - Artificial Intelligence and the Shaping of Democracy (https://democracy-ai.eu/).

The project is led by the Institute for Didactics of Democracy from Leibniz University Hannover (https://www.idd.uni-hannover.de/de/), in partnership with:
- Arbeit und Leben e.V. (https://www.arbeitundleben.de/)
- Höhere Technische Lehranstalt (HTL) Wien West (https://www.htlwienwest.at/)
- Demokratiezentrum Wien (https://www.demokratiezentrum.org/)
- Austrian Academy of Sciences - Institute of Technology Assessment (https://www.oeaw.ac.at/ita/en/)
- LUCA School of Arts (https://www.luca-arts.be/en)
